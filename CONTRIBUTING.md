# Contributing to Awesome X Twitter Growth Tools

Thank you for contributing! Here's how to add a tool.

## Requirements

Tools must be:
- Actively maintained (updated in the last 12 months)
- Specifically useful for X/Twitter growth or management
- Not purely promotional landing pages — must have genuine utility
- Available publicly (free or paid)

## How to submit

1. Fork this repository
2. Add your tool to the relevant section in `README.md`
3. Use this format: `**[Tool Name](URL)** — One sentence description of what it does.`
4. Keep entries alphabetical within each section
5. Submit a pull request with a short description of the tool

## What we don't accept

- Tools that are no longer maintained
- Duplicate entries
- Tools with no clear X/Twitter focus
- Paid promotions or sponsored insertions

## Questions?

Open an issue and we'll respond within a few days.
